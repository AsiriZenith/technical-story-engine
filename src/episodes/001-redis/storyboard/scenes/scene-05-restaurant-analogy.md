# Scene 05 — Restaurant: Repeated Work

## Purpose
Make repeated legitimate work intuitive through a compact restaurant analogy, before the cache concept is introduced.

## Narrative Beat
First order: customer -> cashier -> chef -> burger, ~10 min. A different customer orders the same burger again; same cashier, same chef, same work again, ~10 min again. Main idea: "Same work. Again."

## Status
Implemented, human approved.

## Visual Approach
Both beats are user-supplied PNG assets (`scene05FirstOrder`, `scene05RepeatOrder`) rendered exactly as supplied; their visible windows do not overlap since both carry baked English labels ("First order" / "~10 min" / "Same order again" / "~10 min again"). The "Same work. Again." takeaway is supplemental Remotion text, localized, never baked into the artwork.

## Assets Used
`scene05FirstOrder`, `scene05RepeatOrder` (both `approved`, human-approved 2026-09-14).

## Known Issues
None beyond the shared baked-English-label localization limitation.

## Review Notes
The cache/ready-shelf solution is intentionally not introduced yet in this scene — that belongs to Scene 06. Do not let this scene anticipate the resolution.
